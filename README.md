### 🌟 Features

- 🌐 Fetches random quotes from an external API
- 🔍 Displays quote text and author dynamically
- ▶️ Button to get a new quote instantly
- 💲 Tweet the current quote with one click
- 🌈 Responsive design with elegant UI

---

### 🚀 Live Demo

[Click here to try the app 🔗](https://vrajchariot.github.io/Quote-Generator/)

### 🛠️ Tech Stack

- **Frontend**: HTML5, CSS3, JavaScript (ES6)
- **API**: Quote API (Forismatic or similar)
- **Hosting**: GitHub Pages

---

### 🧠 What I Learned

- Fetching data asynchronously using `fetch()` and async/await
- DOM manipulation to update UI dynamically
- Handling API errors and fallback mechanisms
- Enhancing user experience with loaders and interactions
